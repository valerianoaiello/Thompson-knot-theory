# Logs of the runs

Console output of the runs of `run.py`, `identify.sage`, `make_table.py`, `reverse_scan.py` and
`verify_reverse.py` that produced the results in `results/`. They are kept for reference only.
`identify_log_sequential_partial.txt` and `identify_F3vec_log_interrupted.txt` are logs of runs that were
interrupted and later repeated.
